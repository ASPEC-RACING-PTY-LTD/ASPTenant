# Testing utilities

`@aspec/testing` is a development-only toolkit for Node.js apps. Use it to scaffold Vitest, drive HTTP APIs with a fluent client, isolate SQLite and PostgreSQL fixtures, build seeded factories, sign test JWTs, mock fetch and local servers, and gate coverage in CI.

Install as a dev dependency. Zero runtime dependencies are pulled into production builds. Optional peers: Vitest, Express, Fastify, Hono and `pg`.
